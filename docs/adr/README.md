# docs/adr/ — Architecture Decision Records

Index of all ADRs. Copy `0000-adr-template.md` as `NNNN-<slug>.md` for each new decision, then add a
row below. Next number: **0001**.

The **`when:` column is the router** — one clause naming the work that makes this ADR required
reading ("touching the aggregation tool", "any new external dependency"). Nobody reads the whole
folder: a task's `## Required reading` list (spec) and this column pick the 1–2 that apply, the
rest stay unread (same pattern as `LESSONS.md ## Index`). An ADR whose `when:` you can't write is
usually a doc, not a decision.
