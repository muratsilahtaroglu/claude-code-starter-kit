# docs/lessons-retired.md — lessons that turned out to be WRONG (TEMPLATE)

> A `LESSONS.md` entry that later proved false is moved here VERBATIM by `/keel-distill`, newest
> first, with a dated `RETIRED <YYYY-MM-DD>: <why it was wrong · what replaced it · evidence path>`
> line under it. This file is **never `@`-imported** — zero context cost, grep on demand (same
> contract as `docs/handover-archive.md`). `LESSONS.md` keeps at most ONE corrective line per
> retired entry ("believed X — measured Y → retired", pointing here), so a session cannot re-learn
> the wrong thing while the always-loaded file stops paying rent for knowledge known to be false.
> Never edit or reorder past entries. A lesson that is still TRUE never comes here — it is PROMOTED
> (rules · skill · ADR · docs) and deleted from LESSONS with one `## Index` router line (rules §9.33).
